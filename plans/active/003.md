## Decisions

- **2026-10-15**: `useScrollScene()` built in this task per Ryan's direction.
- **2026-10-15**: `MotionPageTransition` motion.div needs `position: relative` — without it, non-positioned element sits below canvas (z-index:0 fixed) and is invisible.
- **2026-10-15**: Variant B harness detection uses `useSyncExternalStore` (server snapshot: false, client: from window.location.search).
- **2026-10-15**: tp= freeze for Variant B cannot use AnimatePresence `initial` prop (it's suppressed by `initial={false}` on AnimatePresence on first render). Fix: render a plain div at `opacity: tp` when `hasTp`.
- **2026-10-15**: ADR-0003 recommends Variant B — Motion AnimatePresence. Primary reason: iOS Safari 16/17 is still significant traffic and ViewTransition morph doesn't work there.
- **2026-10-15**: Variant A tp= snaps are identical at all values — browser API cannot be frozen. This is recorded as a finding in ADR-0003 (testability gap).

## Open risks

- Variant A (ViewTransition) — morph doesn't fire on iOS < 18. ADR documents this.
- `useScrollScene()` harness registration: `window.__HARNESS__` may be undefined at useEffect time before `initHarness` completes. Currently guarded but scenes array will be empty on very fast loads. Low priority for lab purposes.
- Heap growth test (done_when #3) requires a full `pnpm verify --full` run against a built app — not yet measured.
