# WebGL

## Canvas

- One `<Canvas>` in `src/gl/CanvasRoot.tsx`, mounted in the root layout so it survives route changes.
- Fixed, full-viewport, `pointer-events: none`, behind content. Sections place scenes with drei `<View track={ref}>` (or a tunnel) so a scene lines up with a DOM element.
- Frame loop is driven by the motion clock (see `docs/MOTION.md`). In harness mode, the canvas renders exactly the frame for `t`.
- Not mounted at all in the `static` tier.

## Scenes

- One folder per scene: `src/gl/scenes/<id>/` with `Scene.tsx`, shaders, and `poster.png` (static-tier fallback, generated by `pnpm snap`).
- Scenes register by id in `src/gl/registry.ts`. Ids match the scroll scene ids where they're linked.
- Inputs to a scene are explicit props/uniforms: `time`, `progress` (scroll), `transition` (0–1), `pointer` (disabled in harness mode). No scene reads global state directly.

## Shaders

- Files: `*.vert`, `*.frag`, shared code in `src/gl/glsl/*.glsl`. Include with `#include "noise.glsl"` (resolved by our loader and by `pnpm shaders`).
- Authored for three.js `ShaderMaterial` on WebGL2. Built-ins (`position`, `uv`, `modelViewMatrix`, `projectionMatrix`, …) are available; don't redeclare them.
- Colors and numeric design values come from `src/gl/glsl/generated/tokens.glsl` (`COLOR_INK_900`, `DURATION_BASE`, …). No literal design colors in GLSL.
- Every uniform is declared in the scene's `uniforms.ts` with a type and default. Uniform names: `uTime`, `uProgress`, `uTransition`, `uResolution`, then scene-specific.
- `pnpm shaders` must pass: it compiles every shader in headless WebGL2 and reports the file and line of any error.

## Performance

- Budgets in `docs/budgets.json`. Measure with `pnpm perf <route>` on the lab page before and after a change.
- Dispose geometries, materials and textures when a scene unregisters. Lab 004 adds a memory check across 20 navigations; it stays in the regression suite.
- Use DPR clamp from tokens (`gl.dpr.max`). Mobile defaults lower.
